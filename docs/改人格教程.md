# 改人格教程（秋实的大肥鱼连接器）

> 菜单名按 AstrBot v4.29.3 / NapCat v4.18.41 原版中文界面核对（来源：AstrBot `dashboard/src/i18n/locales/zh-CN/core/navigation.json`、`features/persona.json`；NapCat WebUI 打包脚本）。

## 一、打开管理后台
1. 在连接器里点「启动」，等「AstrBot 大脑」变绿。
2. **先看按钮上方的黄色「账号 / 密码」卡片**：
   - 账号：`astrbot`
   - 密码：自动生成的随机密码（点「显示」可查看，点「复制密码」可复制）
3. 点「打开管理后台」：连接器会**自动复制密码**并弹窗提示「账号 astrbot，密码已复制，登录页直接粘贴」。点「知道了，打开后台」。
4. 在浏览器登录页：账号填 `astrbot`，密码框按 **Ctrl+V** 粘贴 → 登录。首次登录会要求改密码，改完自己记住；忘了回连接器点「重置」。

## 二、新建人格
1. 左侧菜单找到分组 **「扩展功能」**（可折叠，点开），点 **「人格设定」**（心形图标）。
2. 点 **「创建人格」**（第一次进来是「创建第一个人格」）。
3. 填写：
   - **人格 ID**：随便起个名字，比如 `dafeiyu`
   - **系统提示词**：写人设，例如「你是大肥鱼的看板娘，说话可爱简短，不超过三句」
   - **预设对话**（可选）：点「添加对话对」给几句示范
4. 点 **「保存」**。

## 三、设为默认人格
1. 左侧点 **「配置文件」**。
2. 找到 **「人格」** 一节 → **「默认采用的人格」**，选你刚建的人格 ID。
3. 右下角保存。保存后新对话即生效；老对话可在 QQ 里发 `/reset` 重开。

## 四、其他常用位置
| 想做的事 | 去哪里 |
|---|---|
| 群聊插话频率等 | 左侧「插件」→ group_chat_plus 卡片 →「配置」（插件配置） |
| 换模型 / 换 Key | 左侧「模型提供商」 |
| 看日志 | 左侧「数据与日志」 |
| QQ 登录、连接方式 | 连接器「打开 NapCat WebUI」→「基础信息」/「网络配置」（WS客户端已自动配好，别改） |

## 注意
- 改人格不会额外花钱，但提示词越长，每次对话 token 越多。
- 不要在人设里让机器人冒充真人、发广告或违规内容，否则更易被封号。

## 默认表情包与技能（v1.0.3）

- 整合包已预装 **表情包管理器**（meme_manager）。默认人格「小鱼」的 Tools 里会带上它的工具（`tools=None` 表示全开，含 `search_memes`）。
- 首次启动后台**静默**安装 **DeepSeek 二创表情包** 并设为默认（无下载按钮、无进度条）；之后 AI 可直接发图，无需手动下载。
- 若因网络未能装上：到管理后台 → 插件 → 表情包管理器 → 资源广场，搜索「DeepSeek 二创」安装（兜底，正常情况不必操作）。
- 内置技能 documents / spreadsheets / pdf / skill-creator **默认关闭**（`data/skills.json` + 人格 `skills=[]`）。要开的话在管理后台「技能」页自行打开。
