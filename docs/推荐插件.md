> 这些插件**没有打包进整合包**，需要时在 AstrBot 管理后台「插件 → 插件市场」搜索名字安装。

### 最佳组合（推荐）
**group_chat_plus（自带）+ Iris 记忆（已装）+ 表情包管理器（已装）+ 智能贴表情 + 专业戳一戳 + 输出增强（只开文本清洗）**
→ 会记事、会发表情包、会贴表情、被戳会回嘴、回复不带 markdown；配合整合包默认的「小鱼」人格和原生分段回复，就很像真人了。想要“它主动来找我”再加 Proactive Chat（仅私聊）。

不推荐同时装：多个记忆插件；多个自动发表情包插件；多个“主动回复/心流/群聊增强”插件（和 group_chat_plus 抢着说话、成倍花钱）。

## 为什么插件市场装插件很慢？怎么加速？
- **慢在哪**：插件本体现在多数从官方插件市场的 CDN 下载，不算慢；真正慢的是 ① 部分插件仍从 GitHub 拉取（大陆访问 GitHub 不稳定），② 安装后 AstrBot 用 pip 装 `requirements.txt` 依赖——像 faiss-cpu、boto3、numpy 这种大包要下几十 MB，网络不好时会卡很久甚至超时。
- **加速方法（AstrBot v4.29.3 后台里的设置，已对照源码核对）**：
  1. **GitHub 加速地址**：管理后台「设置 → 网络 → GitHub 加速地址」，选一个加速地址（如 `https://gh-proxy.com`）并可“测试”连通性。
  2. **PyPI 软件仓库地址**（配置项 `pypi_index_url`）：在「配置文件 → 系统配置」里，默认已是阿里云 `https://mirrors.aliyun.com/pypi/simple/`；慢就换成清华 `https://pypi.tuna.tsinghua.edu.cn/simple` 或中科大 `https://pypi.mirrors.ustc.edu.cn/simple`。
  3. **pip 安装额外参数**（`pip_install_arg`）：可填 `--timeout 120` 之类，避免大包下载超时。
  4. **代理**（`http_proxy`）：有自己的代理可填 `http://127.0.0.1:端口`。
- 尽量挑“依赖轻”的插件（上表已标注），装完一个确认能用再装下一个。
