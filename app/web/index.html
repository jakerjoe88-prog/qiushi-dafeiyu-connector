连接 DeepSeek

机器人用 DeepSeek 思考。在 platform.deepseek.com 充值几块钱 → 「API keys」→ 创建，复制 sk- 开头的那串粘贴到下面。

Key 只保存在本机配置文件里，不会显示、也不会上传到别处。

防封提醒：请用注册较久、正常使用过的小号当机器人，千万别用主号；新号最容易被风控。别让它刷屏、拉大量群或发广告。

手机 QQ 扫码登录

用机器人那个 QQ 号的手机 QQ 扫码并确认。以后启动一般会自动登录，不用再扫。

  1. 打开手机 QQ（登录机器人小号）
  2. 点右上角「＋」→「扫一扫」
  3. 扫码后在手机上点「登录」
  4. 控制台三盏灯全绿，就可以聊天了
